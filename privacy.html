Polityka prywatności

Data obowiązywania: 17 listopada 2026 r.

GarminSyncCloud jest osobistym narzędziem użytkownika GitHub misiekturner. Nie udostępnia usług publicznych. Adres kontaktowy dla użytkowników wskazany jest w ekranie zgody OAuth Google.

Zakres danych

  • Garmin: aktywności i pliki treningów oraz wybrane pomiary zdrowotne (sen, HRV, tętno, stres, Body Battery).
  • Intervals.icu: dobowe wskaźniki CTL, ATL, Ramp Rate oraz eFTP, gdy dostępne; bez kopiowania aktywności.
  • Google Drive: indeksy, raporty i pliki archiwum w prywatnym folderze _Garmin_sync.

Cel i uprawnienia

Google OAuth umożliwia rclone odczyt poprzedniej historii i aktualizację danych w Google Drive. Udzielony zakres OAuth może umożliwiać szerszy dostęp niż jeden folder, ale skrypt jest skonfigurowany do pracy w _Garmin_sync.

Przekazywanie i przechowywanie

Przetwarzanie korzysta z usług Garmin Connect, Intervals.icu, tymczasowych maszyn GitHub Actions i prywatnego konta Google Drive. Sekrety połączeń są przechowywane w zabezpieczonych sekretach repozytorium GitHub. Dzienniki mogą zawierać informacje diagnostyczne. Dane nie są sprzedawane, wykorzystywane do reklam ani publikowane w ramach tej witryny.

Retencja i cofnięcie zgody

Pliki pozostają na Dysku Google do czasu usunięcia przez właściciela. Dzienniki podlegają zasadom retencji GitHub. Dostęp OAuth można odwołać na stronie połączeń konta Google. Cofnięcie zgody zatrzymuje synchronizację, ale nie usuwa już zapisanych plików.

Ta strona

Witryna jest statyczna i nie zawiera własnych trackerów, reklam ani formularzy. GitHub Pages może zbierać techniczne logi dostępu zgodnie z zasadami serwisu.

Zasady Google API

Wykorzystanie danych Google jest zgodne z Google API Services User Data Policy, w tym zasadą ograniczonego użycia (Limited Use). Dane są używane wyłącznie do opisanej synchronizacji.

Zmiany

Zmiany polityki będą publikowane pod tym samym adresem wraz z nową datą.
